## Task 3 --- Password Analysis

Evaluate the following passwords:

-   123456
  Too simplistic and too systematic
-   qwerty
  Based on a dictionary word
-   P@ssword1
  Ok
-   correcthorsebatterystaple
  Ok

### Questions

1.  Which passwords are weak? 123456 and qwerty
2.  Which password is strongest? P@ssword1 and correcthorsebatterystaple with the exception of satoru gojo of course
3.  Why? They make use of capitalization, long length, and special characters.

### Reflection

Explain what you learned about password strength.

Use of special characters, numbers, and capitalization as well as longer length makes password strength
